# Data provenance

`smartds/` contains public NREL SMART-DS v1.0 (2018), AUS/P1U feeder
`p1uhs19_1247--p1udt17263` files, downloaded 2026-09-25.

Source: https://oedi-data-lake.s3.amazonaws.com/SMART-DS/v1.0/2018/AUS/P1U/scenarios/base_timeseries/opendss/p1uhs19_1247/p1uhs19_1247--p1udt17263/

Dataset: https://data.openei.org/submissions/2981
License: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/
Attribution: National Renewable Energy Laboratory (NREL), SMART-DS Synthetic Models for Advanced, Realistic Testing: Distribution Systems and Scenarios.

Raw source files are retained unchanged. `Substation.dss` is the parent substation's original master, for reference. Neither original master is executed: they reference full-year load profiles which are not downloaded. `sim/feeder.py` loads the electrical elements and removes only `yearly=` loadshape references for snapshot simulation. The source is 1.03 pu as in the feeder master.

`scenario-inputs.csv` is generated by `python -m sim.build_replays`. Its price and load columns are explicitly **ASSUMPTION**, not extracted ERCOT/ResStock history. It also records solved outputs for auditing.

Changes made in memory for the demo:

- Winding kVA is used as the thermal limit; the source's `normhkva` permits 110%. No transformer impedances or winding ratings are rewritten.
- One primary segment `l(r:p1udt13267-p1udt22607)` is lengthened electrically from 0.775624 km to 2.326872 km. Geography is unchanged.
- 96 Core devices are assigned to eligible 120/240 V home buses, with 24 concentrated around a selected actual geographic cluster. All IDs are exported in `ui/dist/model.json`.
- Residential baseline kW/kvar are scaled by a scripted 5-minute factor, preserving the source's power factors.
- Core devices are unity-power-factor signed loads on their existing line-to-line 240 V connection. Charging is positive kW. Energy/SoC is tracked outside DSS with efficiency and reserve limits.

The original research's 1,012-customer figure differs from this import's 1,010 distinct load buses. We display the imported count; 1,007 support the chosen split-phase Core model, 96 are occupied, leaving 911 candidates. Three nonresidential connections remain in power flow but are excluded from battery siting.
