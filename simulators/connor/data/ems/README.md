# data/ems

`freq-series.json` is a verbatim copy of the root app's `ui/data/ems/freq-series.json`: ERCOT system frequency, RoCoF, time error, PRC and inertia for 25 Sep 2026 at one-minute resolution, with its own `provenance`, `sources` and `status_legend` (REAL = public ERCOT data, which the dashboard shows as SOURCED). ERCOT data may be redistributed in analyses; no ERCOT marks are used. The dashboard reads it for the five system cards; no feeder simulator produces these.
